# Student Management System 🎓

A full-stack Student Management System developed using React.js, Java Spring Boot, MySQL, Hibernate/JPA, JDBC, and REST APIs.

## Features

- Admin login
- Add student
- View students
- Update student
- Delete student
- Search students
- Form validation
- MySQL database
- REST APIs
- Responsive React frontend

## Technologies Used

### Frontend
- React.js
- JavaScript
- HTML
- CSS
- Axios

### Backend
- Java
- Spring Boot
- Hibernate
- JDBC
- REST API

### Database
- MySQL
- SQL
